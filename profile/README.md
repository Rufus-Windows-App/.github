## 💾 What It Is
Rufus for Windows is a free, no-fuss tool for making bootable USB drives. Feed it an ISO — Windows 11, Windows 10, or a Linux distribution — choose your USB stick, and it writes bootable install media in minutes. It works with both UEFI and BIOS, lets you pick the partition scheme, and runs portably without installation. Tiny, quick, and reliable, this Rufus download is the standard way to build a bootable USB on a Windows PC.

## ⭐ Key Features
> A free, portable USB tool that writes bootable drives in minutes.

- 💿 **ISO to USB** — Turn any bootable ISO into a USB drive.
- 🪟 **Windows and Linux** — Create install media for Windows 11, Windows 10, and Linux.
- ⚙️ **UEFI and BIOS** — Boot on modern and legacy systems alike.
- 🗂️ **Scheme options** — Choose GPT or MBR and the file system.
- 🧳 **Portable** — Run without installing anything.

## 👣 First Steps
1. Open Rufus and insert your USB drive.
2. Select the device.
3. Choose your ISO.
4. Confirm the options.
5. Click Start to write the bootable USB.
